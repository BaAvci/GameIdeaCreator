# Game Idea Creator

**Important!!! PUBLIC STEAM API IS DEPRECATED AND THIS APP DOESN'T WORK ANYMORE**

This app gets all games on steam and saves them in a data base.

The data includes name and genre.

When a user want's to create a new idea, he can ask the app for a random amount of games and it's genres.

The use then can look up those games and look for gameplay online.

With that info the user can create a, maybe, unique gameplay.

Example: Call of Duty, Age of Empires and Osu.
